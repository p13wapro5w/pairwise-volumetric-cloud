# pairwise-volumetric-cloud

云层边缘在相机俯仰时出现一条条硬台阶，raymarch 用固定世界步长，远处采样不足近处过密；密度 3D 纹理没按步长选 mip，低频噪声被高频细节盖住；光照只采样太阳方向，云底缺少多次散射的暖色；阴影步进和主步进不同步，云自己给自己投出条纹；噪声偏移每帧随机重置，静止画面像沸腾；云与半透明粒子共用深度排序，飞机尾迹被云吞掉；半分辨率渲染上采样没做深度保边，云边出现锯齿光晕；时域重投影没有运动矢量，相机横移时云层拖影；低空雾密度直接加进云密度，山谷变成一堵白墙；性能档把步数减半却没加抖动，云层出现明显分层；远处云用公告板替代，切换距离处密度突然跳变。render/volumetric_cloud.py 是核心，tests/test_volumetric_cloud.py 15个红。要修的是：步长按视深自适应；密度纹理按步长选 mip；光照加多次散射近似；阴影步进对齐主步进；噪声偏移按时间连续；云与粒子分层排序；上采样按深度保边；重投影带运动矢量；雾与云分开积分；降档加蓝噪抖动；远近表示按密度过渡。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
